# Tabelas em SQL

Modelagem de um banco simples com duas tabelas relacionadas (`clientes` e `pedidos`), dados de exemplo e uma consulta com `JOIN`.

## Tecnologias
- SQL padrão (testado em SQLite)

## Como rodar
Em qualquer ferramenta SQL, ou no SQLite:
```bash
sqlite3 loja.db < tabelas.sql
```

## O que pratiquei
`CREATE TABLE`, chave primária e estrangeira, `INSERT`, `JOIN` e `GROUP BY`.
